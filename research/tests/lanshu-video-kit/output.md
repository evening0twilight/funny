# 实测记录：lanshu-video-kit（cclank/lanshu-awesome-ai-video-kit）

- 输入：`research/tests/input-news-01.md`（AIHOT 热点 No.01：MiniMax M3.1 Flash 发布）
- 用户请求：给这条 AI 新闻做一条 **15 秒竖屏短片**（抖音），要能直接粘进国内视频模型
- 执行方式：按仓库路由执行 3 个 skill 链路：`model-selector` → `seedance-storyboard`（+ `methodology/03-分镜时序.md`、`06-约束词清单.md`）→ `seedance-debugger` 的检查清单

## Step A — model-selector：选模型

按 `skills/model-selector/SKILL.md` 的能力矩阵，本次需求是「中文 + 竖屏 + 15 秒 + 要贴新闻文字 + 国内可用」：

| 候选 | 中文 | 音频 | 时长 | 国内可用 | 结论 |
|---|---|---|---|---|---|
| 即梦 3.0 | ★★★★★ | ★★ | 15s | ✓ | **主选**：中文标点/文字渲染最稳，剪映可直接接 |
| Seedance 2.0 | ★★★ | — | 15s | ✓ | **备选**：多镜头叙事更强，但生成文字易糊 |
| Kling 3.0 | ★★★★★ | ★★★★ | 2m | ✓ | 备选：要口播+口型才用，15s 资讯片杀鸡用牛刀 |

→ 主选 **即梦 3.0（15s 竖屏）**，备选 Seedance 2.0。

## Step B — seedance-storyboard：剧情 → 多镜头分镜

按 `skills/seedance-storyboard/SKILL.md`：把剧情拆成 3 个关键节拍（15s 上限 → 3 镜最稳），每镜按「运镜 / 主体动作表情 / 位置空间 / 音频」四维写，`镜头1/2/3` 标识，**不写死 00-03s 这类时长**（methodology/03 明确说模型对精确时间支持不稳定）。

```
竖屏 9:16，中文新闻速报短片，整体为干净的深色科技质感，暗蓝底 + 单一暖白光，全片风格和色调保持一致，无风格漂移。

镜头 1：固定机位中景，一个年轻程序员坐在深夜的工位前，背对走廊，屏幕的冷光打在他侧脸上；他先是盯着屏幕停顿，随后手指在键盘上敲了两下又停住，眉头轻微皱起，露出疑惑的神态；桌面上有一个没喝完的咖啡杯和散乱的便签。
镜头 2：镜头快速推近到屏幕特写，屏幕上先是浮现一个模糊的模型剪影图标，随后图标边缘碎裂散开，露出一个简洁的模型标识；画面轻微震动，光晕从屏幕中心向外扩散；背景是继续闪烁的服务器指示灯。
镜头 3：镜头缓慢拉远，回到程序员的中景，他向后靠在椅背上，肩膀放松下来，嘴角只有一个很轻的弧度，没有大笑；前景是半透明的数据流粒子缓慢飘过，画面最后定格在工位与屏幕的稳定构图上。

音频：镜头 1 只有键盘敲击声和空调低频嗡鸣；镜头 2 加入一声短促的电子提示音和数据碎裂的细碎音效；镜头 3 环境音渐弱，保留很轻的低频余韵，不出现人声与歌词。

约束：不要生成水印，不要生成 Logo，保持无字幕，避免生成任何文字或字幕，人物面部稳定不变形，身体比例稳定不变形，动作连贯自然不僵硬，无穿模无卡顿无闪烁，全程保持深色科技质感风格，色调一致，同一画面中仅保留单个对应人物，不出现人物重复复刻。
```

**为什么这样写（对齐 methodology）**

- 每个镜头只有 1 种运镜（推近 / 固定 / 拉远）—— `seedance-storyboard` 检查项 1。
- 主体用稳定标签「程序员」指代，避免多主体代指混乱；单主体时也显式写「单个对应人物」—— `06-约束词清单` 防双胞胎。
- 动作具体到肢体（「敲两下又停住」「向后靠」），不用「很酷」「很燃」这类抽象词。
- 情绪外化：疑惑 = 眉头轻微皱起；释然 = 肩膀放松 + 很轻的弧度（对应 `04-情绪外化表`）。
- 音频逐镜描述，不用 BGM 托情绪。
- 约束词直接套用 `06-约束词清单` 的「必加 3 条 + 稳定性 + 风格一致性 + 主体一致性」。

## Step C — 自检（seedance-storyboard 检查清单 + 通用检查）

| 检查项 | 结果 |
|---|---|
| 每镜只 1 种运镜 | ✅ |
| 多主体用稳定标签 | ✅（单主体，仍显式声明） |
| 显式指代主体 | ✅「程序员」「屏幕」 |
| 动作具体到肢体 | ✅ |
| 情绪具象外化 | ✅ |
| 镜头数 3-5 | ✅ 3 |
| 不写死秒数 | ✅ |
| 必加约束词 | ✅ 水印/Logo/字幕 3 条全有 |
| 9:16 竖屏 | ✅ 首行声明 |
| 中文输出可直接用 | ✅ |

## Step D — 模型适配补充（按 model-selector 矩阵）

- **即梦 3.0**：上段直接用，15s 单条可出；中文文字渲染虽强，但仍建议「不要生成字幕」，字幕后期加，避免错字。
- **Seedance 2.0**：把「镜头1/2/3」保留，去掉「竖屏 9:16」改在参数里设；负面词单独填字段。
- **Kling 3.0**：若想加口播，改用 `kling-prompter`，并把音频段替换成「人物正对镜头说话，口型与中文口播同步」。

## 结论（给报告的判断）

- 这条提示词**可直接粘进即梦 3.0 生成**，3 个镜头、15 秒、竖屏、无 IP 风险、约束词齐全，属于「拿来就用」级别。
- 它的强项是**模型工程化**：知道每个模型的时长/中文/音频/负面词字段差异，能路由到正确模型；这对国内创作用户比「电影感」更有用。
- 弱项：**只给画面，不给「这条新闻讲什么」的内容结构**。它不会帮你写口播文案，也不会告诉你 15 秒里该讲哪三个信息点 —— 这必须由 A 类文案 skill 或人先定。
