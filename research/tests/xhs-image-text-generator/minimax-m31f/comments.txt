【常见问题回复】
Q1：国内能用吗？
A：官方 API 已上线，走 MiniMax 开放平台；第三方平台（OpenRouter / OpenCode / Cline / Ollama / GMI Cloud）也已上架，Day0 就有。

Q2：和 DeepSeek V4.1 Flash 比哪个强？
A：看你要什么。AA 智能指数 DeepSeek 45、M3.1 Flash 42，但 M3.1 便宜很多、速度快，适合跑量。选型别只看一个分。

Q3：权重 10/23 开放，能本地部署吗？
A：官方说 10 月 23 日开放权重，但许可证未公布。许可证不明之前，别急着做商用规划。

Q4：1M 上下文是真的吗？
A：这条来自第三方账号依据 API 文档的转述，官方发布信息里没有逐项确认，先别当定论。

Q5：值得现在就换吗？
A：免费窗口内值得试；生产环境等许可证和稳定性数据。
