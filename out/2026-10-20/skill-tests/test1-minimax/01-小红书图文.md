### 【正文】

匿名霸榜 10 天的 Space Bunny，真身是 MiniMax M3.1 Flash。🚀

官方确认 Space Bunny 就是它的早期版本。OpenRouter 称它匿名期间连续 10 天居首、处理 56.7T token，回归后免费 72 小时；OpenCode 称它连续 12 天居首、累计 106T token，上架后免费 3 天。

官方口径：成本是 M3 的 1/3，速度约 3 倍，日常输出 200+ TPS。官方评测里，DeepSWE v1.1 得 73.7%，OSWorld V2 得 61.7 分，CyberGym 得 82%。

价格要看清口径。官方附图和 MarkTechPost 给的都是每百万 token 输入 $0.15、输出 $0.60；AIHOT 综述给的人民币口径是输入 1 元、输出 4 元、缓存读取 0.1 元。人民币不是官方中文页面的价目，引用时记得带「综述口径」。⚠️

第三方横评单独看：Artificial Analysis 的智能指数给它 42 分，比 M3 高 13 分，低于 DeepSeek V4.1 Flash 1017 的 45 分；Arena 的 Code Arena WebDev 榜上它 1588 分，开源模型第 12、总榜第 32。

⚠️ 两个先别当定论的地方：

① 权重定在 10 月 23 日开放，AIHOT 综述写的是「许可证尚未公布」。放权重和开源不是一回事，许可条款要等官方文件。

② 网上流传的 1M 上下文，来自第三方账号对 API 文档的转述，官方发布信息没有逐项确认，先别当参数写进选型表。

如果你在写 agent、跑长任务，或者每天要试错很多次，这类按 token 计费的场景值得先测；单次关键推理还是留给更强的模型收尾。

Cline 在发布当天免费，Ollama 和 GMI Cloud 也标了 Day0。🔖 想试的先去各家官方页面看免费入口，别把工作流建在限时免费上。

## 4. 风险与未确认

1. **1M 上下文没写进正文**：素材卡里它是 `unverified`（Testing Catalog 转述），只在正文里作为「别当定论」出现。
2. **200T token 没用**：官方博客写「超过 200 万亿 token」，但 OpenRouter 56.7T 与 OpenCode 106T 两个平台口径加起来也对不上这个量级，正文只引用平台各自的数。
3. **人民币价目是 `third-party`**（AIHOT 综述），正文已标明口径；英文价 $0.15/$0.60 有官方附图与 MarkTechPost 两处支撑。
4. **许可证**：素材卡只有综述一句「许可证尚未公布」，不是官方原文；正文写成「综述写的是」，没有写成官方确认。
5. **免费时效**：72 小时 / 3 天从 10 月 19 日起算，发布越晚剩余越少，正文没写具体截止时刻。
