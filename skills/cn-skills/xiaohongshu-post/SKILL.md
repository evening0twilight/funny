# 小红书笔记写作

帮用户产出可以直接发布的小红书笔记:标题、封面文案、正文、标签一次给齐。

## 为什么小红书要特殊对待

小红书的流量分发由**封面和标题的点击率**决定,笔记能不能进下一个流量池由**前 3 行的完读率和互动率**决定。所以这不是"写一篇短文",而是写三样东西:让人点进来的(封面+标题)、让人读完的(开头三行)、让人点赞收藏的(结尾互动)。

## 工作流程

1. **收集信息**。动笔前确认四件事:主题是什么、写给谁看、核心卖点/信息是什么、希望读者做什么(收藏教程 / 点赞共鸣 / 评论区提问)。用户没说清的,用合理假设代替并列出假设,不要反复追问超过一轮。
2. **确定笔记类型**,套用对应结构(见下)。
3. **产出完整交付物**,格式见"输出格式"。
4. **自检清单**逐项过一遍。

## 三种常见笔记结构

**种草/测评**:一句真实体验开头 → 2~4 个卖点,每个卖点配具体细节(数字、对比、使用场景)→ 提一句不足(真实感是转化率的核心)→ 谁适合买。

**教程/干货**:痛点开头("还在XX吗?")→ 步骤化正文,①②③编号,每步一句话讲完 → 避坑提示 → 引导收藏("怕忘的先收藏")。

**经验/情绪共鸣**:场景化开头让目标人群对号入座 → 讲转变(以前…现在…)→ 提炼可复制的做法 → 共鸣式结尾。

## 标题规则

20 字以内,备选 3 个,覆盖不同公式:

- **数字合集**:"5个让我皮肤变好的习惯|第3个坚持了2年"
- **反差冲突**:"月薪3千和月薪3万,差的真不只是钱"
- **悬念警告**:"求求别再乱买了!我踩过的坑都在这"
- **身份点名**:"打工人必看|通勤1小时原来能干这么多事"
- **利益承诺**:"小白也能学会的剪映教程(附避坑清单)"

## 正文规则

- 300~800 字。超过 800 字完读率断崖式下跌,砍。
- 段落 1~3 行一断,手机上一屏不超过 4 段。
- 开头三行决定生死:直接说结果或抛冲突,禁止"大家好我是XX"式开场。
- emoji 每段最多一个,放在段首做视觉锚点;整篇不超过 8 个,堆 emoji 显得像广告号。
- 口语化,用"我"的视角;称呼按人群选(姐妹们/宝子们/家人们/uu 们),不确定就中性称呼。
- 分点用 ①②③ 或 emoji 列表,小红书排版不支持 Markdown 加粗,不要输出 `**` 语法。

## 标签规则

5~8 个:2~3 个大流量泛标签(#好物分享 #职场)+ 2~3 个精准垂类标签(#机械键盘 #时间管理)+ 1~2 个自定义内容标签。大标签给曝光池,垂类标签给精准人群,缺一不可。

## 输出格式

```
【标题备选】
1. …
2. …
3. …

【封面文案】
主文案(大字,≤10字):…
副文案(小字,可选):…
封面建议:…(一句话描述画面/配色)

【正文】
(可直接复制发布)

【标签】
#标签1 #标签2 …
```

## 示例

输入:"帮我写一篇推广我新开的社区咖啡店的小红书笔记,店在上海浦东,主打手冲和撸猫"

输出(节选):

```
【标题备选】
1. 浦东打工人也有自己的快乐老家了☕
2. 在小区里开了家可以撸猫的咖啡店|第30天
3. 谁懂啊!楼下的手冲+猫咖组合也太治愈了

【封面文案】
主文案:浦东 | 手冲 × 撸猫
副文案:一个可以坐一下午的社区小店
封面建议:猫趴在手冲吧台边的实拍,暖色调

【正文】
开了30天,终于敢发第一篇笔记了☕

坐标浦东,一家藏在小区里的咖啡店,主打手冲,店里还有两只店猫(麻薯和年糕,都亲人)

为什么开在社区?
因为我发现打工人下楼买杯咖啡的距离,决定了幸福感上限 ☕

手冲豆单每周换,现在有云南和埃塞俄比亚两款,不喝酸的可以直接说,帮你调

猫的话…麻薯会在你喝咖啡的时候睡在你旁边,年糕只负责营业可爱

地址放在评论区,来的时候说一声是小红书来的,送一杯浓缩☕

【标签】
#咖啡店探店 #浦东美食 #手冲咖啡 #撸猫日常 #社区咖啡店 #上海探店
```

## 自检清单

- [ ] 标题 ≤20 字,且不是"自嗨式"(读者视角能看出能得到什么)
- [ ] 正文前三行有钩子
- [ ] 没有绝对化用语("最好喝""全网第一""100% 有效"这类违反广告法的表述,换成"我喝过最喜欢的""亲测")
- [ ] 没有输出 Markdown 加粗/标题语法(发布后不渲染)
- [ ] 标签大小搭配,总数 5~8 个
- [ ] 有明确的互动引导(收藏/评论/提问,选一个)
