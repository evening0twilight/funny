# 生图：小红书卡片 / 封面（arcloop 版）

> 平台前提：你在 **arcloop.ai** 手动生成，不是调 API。所有写法都按 arcloop 的真实能力来。
> 规格来源：`arcloop-models.md`（2026-10-20 核实）。

---

## 0. 先选路线（这个决定成败）

| 路线 | 怎么做 | 什么时候用 |
|---|---|---|
| **A. 一次出图带字** | 直接让模型把中文标题画进图里 | 标题短、只改一次、追求快 |
| **B. 无字底图 + 后期加字**（**推荐**） | 先出「没有文字的背景图」，中文在 Canvas / 醒图 / 设计工具里贴 | 资讯号高频出稿、标题经常改 |

为什么推荐 B：
1. arcloop 的图片模型**会自作主张加中文**（官方实测：Sunburst 擅自加了没审批过的标语，还把 `VOL.1` 写坏）
2. 资讯号标题天天变，重生成整张图太贵太慢
3. 文字排版交给设计工具，100% 可控

**只有一种情况用 A**：封面只有 4–10 个字的大标题，且你愿意逐字校对。

---

## 1. 模型怎么选

| 你要什么 | 模型 | 参数 |
|---|---|---|
| 中文标题卡片 / 封面 | **GPT Image 2.5 Sunburst** | 9:16，2K；文字排版官方评级 Excellent |
| 密集信息图（3–5 条要点 + 数字） | **Seedream 5 Pro** | 支持图层拆分，改一处不用重画 |
| 批量草稿 / 九宫格变体 | **Seedream 5 Lite** 或 **GPT Image 2.5 Flare** | 快，成片再换 Pro/Sunburst |
| 无字底图 | 任意，推荐 Seedream 5 Pro（材质更好） | 标题区留暗部低细节 |

> ⚠️ 生成器里的 **Flare / Sunburst 是两个档位**，不是一个模型。选错档位效果差很多。

---

## 2. 比例：3:4 是坑

- **9:16 可以直接出**（图片侧已确认）
- **3:4 在图片侧官方页面查不到 → 视为不支持**
- 兜底：**按 9:16 出图，构图按 3:4 的重心排，后期裁掉上下**（9:16→3:4 只裁高度，不裁宽度）

## 3. 六段式结构（官方 anti-drift 结构，别改顺序）

```
1. 主体（身份/物品）：具体的形、色、材质，1–2 个记忆点
2. 服装/外观：轮廓、面料、色块（信息卡片可跳过，写「无人物」）
3. 构图与姿态：景别 + 只写一个动作
4. 背景环境：一个地点 + 一个视觉任务；需要时写「无可读招牌」
5. 光色风格：材质底层 + 线条/笔触 + 色板
6. 负面约束（必写）：不要文字 / logo / 水印 / 多手多指 / 风格失败项
```

**三条铁律**（官方原文）：
- 顺序不能乱——风格放最前，模型会把人重新设计
- 每块只干一件事
- **空着的块 = 模型自由发挥**

> 注意：arcloop **没有 negative prompt 输入框**。负面约束必须写成第六段塞进提示词，不写等于没写。

## 4. 卡片模板（直接抄改）

### 4.1 信息卡片（无字底图版，推荐）

```
<9:16 竖版，2K>
一张深色信息卡片背景：深蓝黑渐变（#0B1220 → #101A2B），叠加 1px 浅灰网格（间距 48px，不透明度 8%）。
画面上半部分留出大面积低细节暗部作为标题安全区，下半部分放三根等距横向浅灰分隔线，形成四个信息槽位。
材质为磨砂玻璃与阳极氧化铝，主光 5600K 顶部大面积柔光，右侧 45° 一条 4300K 冷白轮廓光只勾边。
无文字、无数字、无 logo、无水印、无人物、无手、无插画、无镜头光晕、无粒子特效。
```

（标题和数字后期在 Canvas / 醒图里贴，位置已经留好了）

### 4.2 带字封面（路线 A，慎用）

```
9:16 竖版信息海报风格，深蓝黑底 + 冰蓝强调色，磨砂玻璃卡片居中。
画面上只显示以下三行文字，逐字照抄，不得增加或修改任何其他文字：
第一行（最大、粗体）：成本砍到1/3
第二行（中号）：速度快3倍
第三行（小号）：10月23日放权重
字体为无衬线黑体，文字左对齐，整体位于画面上方三分之一。
除上述三行外，画面中不得出现任何其他文字、数字、logo、水印、装饰性字符。
```

**用路线 A 必须做三件事**（官方要求）：
1. 文案用引号逐字列出
2. 加一句 `no other text`
3. 生成后 **放大到 100% 逐字校对**——写错一个字就重跑

### 4.3 对比卡 / 数据卡

```
9:16 竖版，深色底（#0B1220），中央一根浅灰基准柱（占高 90%）与一根青色柱（#4DD6E0，占高 30%）并排，
两柱底部对齐，柱体为阳极氧化铝质感，顶部各留一块空白铭牌位（后续贴字），
背景有极淡的水平参考线，顶光 5600K，右侧冷白轮廓光。
无文字、无数字、无刻度、无 logo、无水印、无人物、无粒子、无光晕。
```

## 5. 一份提示词 = 三件套

交给运营的格式固定成：

```
【模型】GPT Image 2.5 Sunburst
【比例/画质】9:16 / 2K
【提示词】
（六段式全文，末尾必带负面约束段）
【后期】标题在 Canvas 里贴在顶部安全区，字号 X
【校对】中文必须 100% 放大核对（路线 A 时）
```

---

## 6. 常见翻车

| 现象 | 原因 | 修法 |
|---|---|---|
| 图上多出奇怪中文 | 没写 `no other text` | 加负面约束 + 逐字校对 |
| 中文写成错别字/乱码 | 路线 A 的通病 | 改路线 B；或换 Seedream 5 Pro |
| 三只手 / 六根手指 | 出现人物 | 资讯卡片索性写「无人物」 |
| 画面很「高级」但信息量为零 | 没有构图任务 | 第四段必须写「视觉任务」 |
| 每张风格都不一样 | 没固定色板与材质 | 建一个「视觉系统」文案，每条提示词复用 |
| 3:4 出不来 | 平台不支持 | 9:16 出图后裁切 |

## 7. 资讯号视觉系统（建议固定下来，每条复用）

把下面这段存成你自己的模板，每次只改主体与构图：

```
色板：底色 #0B1220 → #101A2B；强调色单一青 #4DD6E0；风险色橙 #FF7A45（仅用于警示）
材质：磨砂深灰玻璃（粗糙度 0.55）、阳极氧化铝 #B9C2CC、LED 点阵（点距 2mm）
光：顶部 5600K 大面积柔光箱 + 右侧 45° 4300K 冷白轮廓光
构图：竖版 9:16；信息区在下三分之二；顶部三分之一留标题安全区
禁止：霓虹、粒子爆炸、镜头光晕、胶片颗粒、动漫人物、3D 渲染感
```
