# 事实核验：把「可能会被打脸的地方」提前找出来

> 做 AI 资讯号，翻车 90% 不是文笔问题，是事实问题。
> 这一页是流程，不是建议——按顺序走完再发。

---

## 1. 四步流程

### 第 1 步：把所有数字抽出来

```bash
python3 skills/ai-news-content/scripts/prep_input.py --aihot-story <id> --out material.json
```

`material.json` 里的 `numbers[]` 就是这一条新闻里所有数字。写稿时**只用这里出现过的数**，自己算出来的要标「按…折算」。

### 第 2 步：给每条事实定层级

| tier | 判断标准 | 写稿时的处理 |
|---|---|---|
| `official` | 厂商官方博客/X/文档 | 可直接写，最好带日期 |
| `first-party` | 同一方多渠道一致 | 可直接写 |
| `third-party` | 媒体报道、评测机构 | 必须带主体：「据 The Verge 报道」「Artificial Analysis 评测」 |
| `unverified` | 单一转述、社区传言 | 不写；非写不可时用「有说法称，未获官方确认」 |

### 第 3 步：找矛盾

同一件事两个来源对不上，是最容易出事的地方。三种处理：
1. **两个都写，各自归属**（最稳）
2. 只写官方口径，其余不提
3. 明确写「两个口径不一致」（最诚实，也最容易建立专业感）

### 第 4 步：机器复核

```bash
python3 skills/ai-news-content/scripts/check_copy.py 稿件.md --material material.json
```

`数字可溯源` 那一项会把稿子里素材卡没有的数字列出来——每一个都要能解释。

## 2. 五类高频错误（都是我们实测踩过的）

### ① 把「缺席」当「默认」
❌ 「许可证不会公布」
✅ 「截至 10 月 20 日抓取，许可证信息尚未公布」

> 缺席只能描述成「当时的状态」，不能推断成结论。而且**必须带日期锚点**，否则过两天就变成假话。

### ② 把转述当官方
❌ 「支持 1M 上下文」
✅ 「有第三方账号依据 API 文档称支持 1M 上下文，官方发布信息未逐项确认」

> 官方发布里没写的东西，一律是转述。

### ③ 两个口径并排当事实
❌ 「官方称成本为 1/3，定价约为一半」
✅ 「官方称成本为上一代的 1/3；不过 MarkTechPost 和 Artificial Analysis 的解读是定价约降到一半——两个口径不是一回事」

> 一个是「成本」，一个是「定价」，主语不同。并排写会让人觉得矛盾，分开写显得专业。

### ④ 自己算的数当原文
❌ 「输入 1 元 / 百万 token」
✅ 「输入 $0.15 / 百万 token（按约 7 的汇率折算，约 1 元）」

> 折算、增减幅、百分比计算，全部要标明是你算的。

### ⑤ 数量级或单位搞错
「56.7T token」不是「56.7 亿」，`T` = 万亿。中文报道里 T/B/M 混用是常见乱子。
**规则：原文用什么单位，你就用什么单位，不要自己换算成中文数量级。**

## 3. 归属话术模板（直接用）

| 场景 | 写法 |
|---|---|
| 官方明说 | 「官方称……」/「MiniMax 在官方博客里写……」 |
| 媒体报道 | 「据 The Verge 报道……」 |
| 评测机构 | 「Artificial Analysis 的评测给它 42 分」 |
| 第三方转述 | 「有账号依据 API 文档称……，官方未逐项确认」 |
| 两个来源冲突 | 「两个口径不一样：官方说 X，第三方解读是 Y」 |
| 预测 | 「按……推算」「如果……」「大概率……」（**不许写「将」「确定」**） |
| 你自己算的 | 「按约 7 的汇率折算，约……」 |

## 4. 发布前的五个问题

1. 稿子里每个数字，我能在素材卡里指出来源吗？
2. 有没有哪句话是「我推断的」但写成了「事实」？
3. 有没有把「未公布」写成「没有」？
4. 有没有把「第三方说」写成「官方说」？
5. 如果明天官方发公告打脸，这条稿子哪句话最先出事？

第 5 个问题最有价值——**它就是审校该盯的地方**。

---

## 5. 预测型内容的额外纪律

预测型（如「Codex 重置窗口」）完播率高，但翻车成本也高。三条硬规则：

1. **全篇用条件词**：按…推算 / 大概率 / 我倾向 / 最晚不超过。禁止「即将」「确定」「官方已安排」
2. **写清样本量**：「只有 3 个样本，两次间隔推不出周期」——这不是示弱，是专业
3. **预设失败话术**：内容里就写好「如果没发生，我们怎么解释」，发出去之前先想好二条怎么接

> 预测对了涨信任，预测错了也是互动——前提是你从头到尾都说了这是预测。

## 6. 检查器的边界（别把它当免死金牌）

`check_copy.py` 的数字溯源按 **token 集合**比对素材卡里的「事实文本」（标题/摘要/正文/facts/numbers/quotes/timeline），不拿 URL、id 这些噪声字段去凑。

它**能**抓到：
- 编造的数字（88.8、999）
- 素材卡里根本没有的数值
- 把「未公布」写成确定结论（靠人工清单）

它**抓不到**，必须人看：
- **单位不匹配**：素材卡里有「100 万 token」，你写成「100 元」，token 相同 → 放过
- **语境错位**：素材卡里 73.7 是 DeepSWE 得分，你写成「准确率 73.7%」→ token 相同 → 放过
- **推断当事实**：「没公布」→「不会公布」这种语义变化
- **归属错位**：把第三方的数字写成官方的

所以流程是：**机器过一遍筛掉低级错误，人再过一遍专挑语义。** 两者都不能省。
