# 梗引擎：先让人停下来，再谈信息

> 这个 skill 的其他章节都在保证「内容不出错」。这一章负责「内容有人看」。
> 它是可选的一层，但也是**决定生死的一层**——没人点开，事实再准也等于零。

---

## 0. 先接受一个事实：没人关心 AI 新闻

你的观众不关心「MiniMax 发布了 M3.1 Flash」。
他们关心的是：**这跟我有什么关系 / 这好不好笑 / 我又能拿它去跟谁抬杠**。

所以整活的本质不是「把新闻说得好玩」，是**给一个已经存在的情绪，找一个 AI 的出口**：

| 观众本来的情绪 | 你能给的出口 |
|---|---|
| 「又出新模型，卷死了」 | 把模型发布做成「拳击赛称重」 |
| 「额度又没了，Tibo 快重置」 | 把重置做成「13:0 带走 no reset」 |
| 「AI 又要取代我」 | 「AI 招聘会，岗位：你」 |
| 「我不信它真有那么强」 | 「现场测给你看」 |

**先找情绪，再找画面。** 顺序反了就会做出一条「信息很全但没人看」的东西。

## 1. 注意力公式（用来判断一个梗能不能立住）

```
注意力 ≈ 熟悉感 × 意外感 × 情绪强度 ÷ 理解成本
```

| 因子 | 怎么加 | 怎么减 |
|---|---|---|
| **熟悉感** | 用一个所有人都认识的东西当壳：电影海报、赛事比分、综艺字幕、游戏 UI | 用只有圈内人懂的黑话当壳 |
| **意外感** | 壳和内容错位（电影海报里写的是「模型降价」） | 壳和内容顺理成章（AI 新闻配 AI 新闻） |
| **情绪强度** | 荒诞、愤怒、爽、嘲、嗑 | 中立陈述 |
| **理解成本** | 3 秒内能看懂画面在说什么 | 需要读 3 行字才懂 |

**自检三问**：
1. 不懂 AI 的人，看第一眼能不能笑/愣一下？
2. 懂 AI 的人，看第二眼能不能 get 到梗？
3. 两个都答不出 → 换方向，别优化文案。

## 2. 三种借势机制（几乎所有爆款梗都在这三类里）

### 机制 A：置换（把熟悉角色换成我们的主体）
> 鹈鹕骑车、秦始皇骑熊 都是这一类：**熟悉的荒诞动作 + 不该出现的主体**。

公式：`[熟悉场景/动作] × [我们的主体]`
- 「Tibo 骑着鹈鹕发重置卡」
- 「OpenAI 的发布会开在菜市场」
- 「新模型入职第一天，工位在厕所旁边」

**关键**：场景越熟、主体越离谱，反差越大。别选「赛博朋克霓虹实验室」这种本来就抽象的场景。

### 机制 B：对决（做成比分/对抗/排名）
> 用户举的「reset 把 no reset 用 13:0 揍回家了」就是这个。

公式：`[A] 13 : 0 [B]` + 赛事级包装（比分牌、解说腔、夺冠画面）
- 「M3.1 Flash vs DeepSeek V4.1：成本擂台，一方提前降重」
- 「免费额度 vs 钱包：0 秒 KO」
- 赛事借势：LOL 世界赛、VCT 冠军赛的赛制/名场面包装

**关键**：比分必须**明显是玩笑**（悬殊到不可能当真），否则会被当成假赛果。

### 机制 C：预告（电影/剧集式悬念）
> 大火的、正在预热期的电影，海报结构天然适合 parody。

公式：`[电影海报结构] × [AI 事件]` + 一句 tagline
- 「《许可证》—— 10 月 23 日，全国上映（暂未定档）」
- 「《最后一个人类员工》」
- 「《重置》第二季：这次真的重置」

**关键**：**改结构不改 logo**。不要 P 官方 logo、不要用官方剧照，用「同款构图 + 自己的视觉」表达。

## 3. 热点雷达：去哪找「现在什么在火」

| 雷达 | 看什么 | 频率 |
|---|---|---|
| 抖音热榜 / 小红书热搜 | 大众情绪、梗的传播形态 | 每小时 |
| 微博热搜 | 突发事件、争议话题 | 每小时 |
| B 站热门 / 鬼畜区 | 二创手法、年轻人语言 | 每天 |
| 猫眼/淘票票 待映片单 | 电影预热期（**最佳借势窗口**） | 每周 |
| QQ 音乐/网易云 热歌榜 | 卡点 BGM | 每周 |
| 赛事赛程（LOL S 赛 / VCT / 瓦罗兰特） | 比赛日 = 当天流量高峰 | 赛程表 |
| AI 整活梗库（鹈鹕骑车类） | 荒诞 AI 视频的流行范式 | 每天 |

**借势时间窗**：电影预热期 > 上映首周 > 长尾；赛事当天 > 次日。
**过了窗口的梗不要硬蹭**，会显得不专业。

## 4. 匹配矩阵：新闻类型 × 梗机制

| 新闻类型 | 首选机制 | 次选 | 举例 |
|---|---|---|---|
| 模型发布 / 测评 | 对决 | 预告 | 「新模型称重现场」 |
| 降价 / 免费 | 比分对决 | 擂台 | 「价格战 13:0」 |
| 封杀 / 禁令 | 预告（惊悚片） | 新闻插播 | 「《禁令》」 |
| 额度重置 | 比分对决 | 荒诞骑乘 | 「reset 13:0 no reset」 |
| 裁员 / 取代岗位 | 招聘广告 parody | 表情包 | 「AI 招聘会」 |
| 失控 / 事故 | 突发新闻插播 | 体育解说 | 「breaking news」 |
| 融资 / 估值 | 排行榜 / 奖杯 | 转会新闻 | 「AI 转会窗」 |
| 许可证 / 条款 | 审判 / 开庭 | 预告 | 「开庭：许可证缺席案」 |

## 5. 整活三级（风险分级，发之前先分类）

| 级别 | 做法 | 风险 | 能不能发 |
|---|---|---|---|
| **L1 借结构** | 用梗的**结构**，画面自己生成，不出现任何真实品牌/人物/赛事素材 | 低 | ✅ 默认走这级 |
| **L2 借符号** | 提到真实名字（LOL、VCT、某电影），用抽象化画面 + 字幕梗 | 中 | ⚠️ 可以，但不伪造 |
| **L3 伪造** | 伪造真实赛果、伪造官方公告、用真人脸、P 官方 logo | 高 | ❌ 不做 |

**L3 的边界特别清楚——注意，被禁止的从来不是「蹭赛事」，而是「伪造真实赛果」**：

| 做法 | 判定 |
|---|---|
| 「reset 13:0 带走 no reset」（虚构队名 + 虚构比分） | ✅ 随便做 |
| 用 LOL/VCT 的**赛制包装**（比分牌、解说腔、夺冠画面）套虚构对决 | ✅ 随便做 |
| 「T1 3:0 击败 XXX」（真实队名 + 编的比分） | ❌ 禁止 |
| 用真实队名 + 官方已公布的**真实**比分 | 🟡 可以，标来源 |

**一句话：可以编剧本，不能编事实。**
- 不能把 Tibo 的真脸做成表情包主角（肖像权）
- 不能把官方 logo 直接贴在自己的 parody 海报上（商标）

## 6. 整活产出契约（每个梗必须给这五样）

```markdown
## 梗：<一句话概念，≤15 字>
- 为什么好笑：<机制 A/B/C + 反转点>
- 借的什么热点：<电影/赛事/音乐/梗，附时间窗口>
- 画面：<一张图还是视频；arcloop 模型与提示词；画面零文字>
- 文案/字幕：<3 个变体，带反转或押韵>
- 风险：L1/L2/L3 + 需要避开的具体元素
```

**判定标准**：把「梗」那一行单独发给一个不看 AI 新闻的朋友，他要是能笑/好奇，这条就成了。

## 7. 从梗到成品：两条路径

### 路径 1：一张图（最快，90% 的整活用这个）
梗概念 → 生图（Seedream 5 Pro 材质强 / GPT Image 2.5 Sunburst 排版强）→ 后期贴字 → 发。
**成本最低、试错最快、平台对图文仍然友好。**

### 路径 2：短视频（15–30 秒，用于「有动作」的梗）
梗概念 → 首帧图 → 图生视频（Vidu Q4 / Kling / Seedance 2.5）→ 拼接 → 卡点 BGM → 字幕。
**只有「动作本身是梗」时才值得做视频**（骑乘、对决、翻车），否则图文就够了。

> 别为了「做视频」而做视频。平台不看形式，看完成度和互动。

## 8. 常见死法

| 死法 | 表现 | 修法 |
|---|---|---|
| 只有信息没有梗 | 「XX 发布 YY，参数如下」 | 换机制 A/B/C |
| 梗太绕 | 需要解释才懂 | 删掉一半信息 |
| 蹭过期热点 | 用两周前的梗 | 换当天/本周的 |
| 伪造过度 | 假赛果、假公告 | 降到 L2 |
| 画面太抽象 | 赛博朋克霓虹一堆 | 用生活场景做壳 |
| 一条里塞三个梗 | 观众一个都记不住 | 一条只用一个梗 |
| 文案比画面长 | 用户不看字 | 画面承担 70% 信息 |
