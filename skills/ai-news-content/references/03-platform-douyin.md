# 抖音 / 视频号平台参考：AI 资讯的口播稿与分镜表

> **这份文件解决什么问题**：给定一条 AI 新闻，写出一条 25–45 秒能拍完的口播稿、一张五列分镜表，并解决"口播和画面长短对不上"这个剪辑台上最常见的问题。
> 量化约束继承自 `cn-skills/douyin-script`（前 3 秒钩子 5 类、语速 240–280 字/分、每句 ≤15 字、每 5–10 秒一个刺激点、至少 2 处数字、分镜表五列、一个 CTA），但**带货假设已整体删掉**：没有小黄车，不做私域引流。资讯号的 CTA 只有三种——涨粉、关注系列、评论区讨论。
> 本文件是写法参考，不是成品；`check_copy.py` 校验的对象是 `out/` 下的成品稿。

## 1. 平台在拿什么给你打分

| 环节 | 平台看什么 | 对资讯号的含义 |
|---|---|---|
| 前 3 秒 | 划走率 | 钩子必须**同时**做到"和内容相关"，纯标题党会被限流 |
| 中段 | 完播率 | 每 5–10 秒给一次新刺激，否则观众在 12 秒左右集体走人 |
| 结尾 | 互动 / 涨粉 | 只给**一个** CTA，给两个等于没给 |

短视频的一半工作量在开头，另一半在**防中途流失**。

### 1.1 五种 CTA，资讯号只用其中三种

| 类型 | 怎么写 | 适用 |
|---|---|---|
| **涨粉型** | "关注我，每天一条 AI 大事" | 日更号，追粉丝量 |
| **关注系列型** | "这是「模型发布」系列的第 X 条，关注追更" | 有固定栏目，追留存 |
| **评论区讨论型** | "你觉得会一起给吗？评论区说一句" | 追评论量和二次推荐 |

一条视频**只选一个**。三选一的判断：追完播率用讨论型，追粉丝用关注系列型，别混着来——混着来观众一个都不做。

> 不做的三件事：不放购物车、不要在口播里引导加联系方式、不要承诺站外资源。

## 2. 硬约束清单（验收标准）

| 项 | 约束 | 为什么硬 |
|---|---|---|
| 前 3 秒 | 必须有钩子，且钩子与内容相关 | 划走只需要一次拇指动作 |
| 语速 | **240–280 字/分**，脚本末尾必须标「口播正文：N 字 → X 秒」 | 文字和时长必须能对上，不然剪辑台上必返工 |
| 句子 | **每句 ≤15 字**，多短句 | 长句跟不上口播节奏，也上不了字幕 |
| 刺激点 | 每 **5–10 秒**一个（新信息 / 转折 / 具体数字） | 防中途流失 |
| 数字 | 全篇**至少 2 处**具体数字 | 数字比形容词有力量 |
| 分镜表 | 五列：`时间｜画面｜口播文案｜字幕/花字｜备注` | 拍摄和剪辑靠它对接 |
| CTA | **只有一个**动作 | 动作一多，用户一个都不做 |
| 合规 | 无绝对化用语；画面零中文（中文后期贴）；AI 生成的画面要勾选 AI 生成声明 | 限流和处罚都从这里来 |

## 3. 前 3 秒：五种钩子（资讯号版）

写完之后自问一句：**如果我是划到这条的人，这 3 秒给了我什么"不划走的理由"？** 答不出来就换钩子。

| 类型 | 公式 | 资讯号示例 | 什么时候用 |
|---|---|---|---|
| **利益前置** | 看完这条你能得到什么 | "30 秒，让你听懂今天群里在转的那条新闻" | 事件复杂、需要预告价值 |
| **反常识** | 和直觉相反的事实 | "成本砍到三分之一，速度反而快了三倍" | 有强对比数字时优先用 |
| **身份点名** | 谁必须看 | "写代码的，这条跟你直接相关" | 垂类新闻，缩窄人群换精准完播 |
| **悬念冲突** | 先抛一个"反常现象" | "一家中国公司的新模型，先被美国一个部门点了名" | 政策、封杀、纠纷类 |
| **进度承诺** | 承按时长讲清一件事 | "30 秒，把这次发布讲清楚" | 合集、系列、干货 |

**三个反例**（都是会被限流或掉完播的写法）：

- 「震惊！AI 圈又炸了」——没说是什么事，钩子和内容无关
- 「大家好，今天我们来聊聊……」——前 3 秒全是暖场
- 「这条视频价值百万」——承诺过头，观众 5 秒内就验证你在吹

## 4. 资讯号的信息节奏设计

### 4.1 一条 30 秒最多讲 3 个信息点

**结论：3 个，多了记不住。** 原因很朴素：观众是划到这条的，不是在听课，工作记忆只能挂住 3 个左右的信息点；而每多一个信息点，就多一次"我好像听懂了，可以划走了"的机会。

| 时长 | 信息点上限 | 结构 |
|---|---|---|
| 15 秒 | 1–2 个 | 钩子 + 一个结论 |
| **30 秒** | **3 个** | 钩子 + 3 个信息点 + CTA |
| 45–60 秒 | 4–5 个 | 需要小标题式转折词分段，否则散 |

**装不下怎么办**：把数字砍掉，而不是把语速提上去。30 秒里放 7 个数字，观众一个都记不住；放 3 个，能记住 2 个。

### 4.2 信息点怎么排序

**反常识 > 悬念 > 数据 > 结论。**

| 位置 | 放什么 | 为什么放这 |
|---|---|---|
| 开头（0–3s） | **反常识**（和预期相反的结论） | 制造"这跟我想的不一样"，这是最直接能压住划走冲动的力量 |
| 中段前半 | **悬念**（"但有一点没说"） | 给观众一个继续看下去的理由 |
| 中段后半 | **数据**（2–3 个硬指标） | 悬念已经吊住了，这时候数据是"证据"，不会被当成念稿 |
| 结尾 | **结论 + CTA** | 只有活到最后的人才听得到，所以结论必须放最后 |

两个例外：

- **政策类**把"谁受影响"提前，读者最关心的是自己，不是条文。
- **预测类**结论必须放在最前说（"我的判断是……"），否则观众不知道你在干嘛。

### 4.3 每 5–10 秒的刺激点排布（30 秒模板）

| 时间 | 这一段干的事 | 刺激手段 |
|---|---|---|
| 0–3s | 钩子 | 反常识数字 / 身份点名 |
| 3–10s | 信息点 1（是什么） | 主体 + 一个价格或时间 |
| 10–18s | 信息点 2（有多强） | 硬指标数字 |
| 18–25s | 信息点 3（有什么坑） | 转折词"但""不过""问题在" |
| 25–30s | 结论 + CTA | 明确的单一动作 |

### 4.4 每句 ≤15 字：长句怎么拆

| 改前（太长） | 改后（短句） |
|---|---|
| "MiniMax 这次发布的 M3.1 Flash 在成本上只有上一代的三分之一，速度却提升了大约三倍" | "成本砍到三分之一。速度还快三倍。" |
| "需要注意的是这个模型虽然开放了权重但许可证信息截至目前仍未公布" | "权重开放了。许可证还没公布。" |
| "如果你打算把它用在商业产品里那可能还需要再等一段时间" | "想商用，还得等。" |

拆句顺带解决了字幕问题：一句一行，后期上字幕不用断句。

## 5. 完整 30 秒示例（素材：MiniMax M3.1 Flash）

> 这份示例是**骨架演示**：口播 124 字 / 30 秒，符合字数与语速规则；但分镜只写了 6 行，实际拍摄可再拆。文字为节选可直接用，配图和视频提示词按 `04`/`05` 另外生成。

### 5.1 三个信息点怎么定的

| # | 信息点 | 放的内容 | 为什么选它 |
|---|---|---|---|
| 1 | **便宜**（反常识） | 成本 1/3、速度 3 倍、$0.15/百万 token | 和直觉相反，且和观众的钱包有关 |
| 2 | **够强**（数据） | 200+ TPS、DeepSWE v1.1 73.7% | 便宜但不行等于没用，必须有证据 |
| 3 | **有坑**（悬念） | 权重 10/23 才开放、许可证未公布 | 制造"所以现在还不能用"的悬念，顺便把事实纪律守住 |

> **注意**：图文版里能塞下 6 个数字（含智能指数 42），30 秒视频塞不下。视频版砍掉一半数字是正常操作，不是偷懒。

### 5.2 黄金 3 秒

> 成本砍到三分之一，速度还快三倍。

### 5.3 分镜表

| 时间 | 画面 | 口播文案 | 字幕/花字 | 备注 |
|---|---|---|---|---|
| 0-3s | 深色底，一个大号「1/3」从画面中心推近，右下角一行小字价格标签 | 成本砍到三分之一，速度还快三倍。 | 大字：1/3 | 钩子，反常识 |
| 3-8s | 官方发布页 / 模型名称打字机式出现，旁边浮出价格标签 | MiniMax 昨天发的 M3.1 Flash。 | 花字：10/19 发布 | 信息点 1，反常识 → 主体 |
| 8-13s | 价格表放大特写，只留「输入 0.15 / 输出 0.60 美元」两行被框住 | 价格：百万 token 输入 0.15 美元。 | 花字：$0.15 / 1M | 数字刺激 |
| 13-18s | 榜单截图快切 + 数字逐行跳出，画面右侧一条进度条跑到 73.7% | 硬指标 200+ TPS，73.7%。 | 花字：200+ TPS | 信息点 2，数据 |
| 18-24s | 镜头切暗，日历翻页，10/23 被高亮圈出 | 但有一点没说。权重 10 月 23 日才开放。 | 花字：10/23 才开放 | 信息点 3，转折 + 悬念 |
| 24-30s | 许可证三个字被打上问号，随后画面收黑，只留 CTA 大字 | 许可证到现在没公布。想商用，还得等。关注一下，23 号回来对答案。 | 花字：待定 → 关注追更 | 结论 + CTA |

### 5.4 口播全文（可直接提词）

```
成本砍到三分之一，速度还快三倍。
MiniMax 昨天发的 M3.1 Flash。
价格：百万 token 输入 0.15 美元。
硬指标 200+ TPS，73.7%。
但有一点没说。
权重 10 月 23 日才开放。
许可证到现在没公布。
想商用，还得等。
关注一下，23 号回来对答案。
```

口播正文：124 字 → 30 秒（约 248 字/分）

BGM：低频脉冲 + 轻鼓点，鼓点落在 8s / 13s / 18s 三次数字切换处；版权走平台曲库。
字幕：默认开启，逐句一行；数字单独放大一号。
出镜：可全屏口播出镜，也可用"口播画中画 + 画面铺满"；真人出镜是资讯号最稳的省钱方案。

## 6. 口播与画面的对齐

### 6.1 先定稿，再剪画面

口播是主轴，画面跟着口播走。**不要先剪好片子再往上对口播**——那是返工率最高的做法。

### 6.2 字数 ↔ 秒数的换算

- 按 248 字/分：**1 秒 ≈ 4.1 个可见字符**（含数字、英文）
- 反向用：字数 ÷ 4.1 ≈ 需要几秒
- 删 **15 字 ≈ 省 3.6 秒**——这就是"压稿"的单位

每个分镜行都过一遍：`这行口播的字数 ÷ 4.1` 和 `时间跨度` 是否匹配？差超过 1 秒就拆行或删句。

### 6.3 口播比画面长怎么办

只有两条合法路径：**补镜** 或 **压稿**。

| 路径 | 怎么做 | 代价 |
|---|---|---|
| **补镜** | 按 6.4 的清单补 2–3 秒的 B-roll / 图卡 / 空镜 | 多花 10 分钟找素材 |
| **压稿** | 删形容词、删过渡句、合并同义句，按 15 字 ≈ 3.6 秒往下砍 | 信息量减少，但节奏更快 |

**明确禁止：慢放凑时长。** 三个理由：
1. 平台会判低质（画面长时间无变化 + 音画拖沓是明显特征）
2. 慢放的人声听上去像卡带，完播率反而掉
3. 慢放会撞剪辑软件的负面词/审核词，成片发不出去

**兜底方案**：差 2 秒以内，直接补一张数据卡静帧（2 秒静止图 + 轻微推近），比什么都不补强，比慢放安全。

### 6.4 补镜清单

| 素材 | 从哪来 | 版权注意 |
|---|---|---|
| 官方发布页 / 参数表截图 | 厂商官网、官方博客 | 报道性使用，字幕注明来源 |
| 榜单 / 跑分截图 | 评测机构页面 | 注明榜单名与日期，别裁掉主体 |
| 价格表、对比表 | 自己做 | 最安全，随便用 |
| 键盘、屏幕、机箱、机房空镜 | 自己拍或平台曲库 | 平台曲库素材要看清授权 |
| 日历 / 倒计时 / 进度条动画 | 剪辑软件内置 | 安全 |
| 出镜口播 | 手机支架即可 | 最稳，AI 感最低 |
| 别人的短视频、影视、游戏画面 | —— | 禁止：侵权 + 搬运必限流 |

### 6.5 画面比口播长怎么办

不要在中间硬塞口播，也不要加速。两种收尾：
- 结尾留 **0.5–1 秒静帧**再切黑（留气口，观众才来得及点关注）
- 中间的多余时长交给 **数据卡静帧 + 字幕强调**，不要用"嗯""那个"填

### 6.6 画面里不要出现中文

- 视频提示词一律写英文，明确 `no text, no letters, no captions`
- 中文标题、花字、字幕**全部后期贴**
- 画面是 AI 生成的，发布页勾选 AI 生成声明并加角标（依据见 `references/07-compliance.md`）

## 7. 输出格式（照抄这个骨架）

交付物就是四块，顺序别换：

1. **黄金 3 秒**：一行钩子，≤15 字。
2. **信息点**：最多 3 条，按"反常识 → 悬念 → 数据"各标一行；超过 3 条先砍，别加语速。
3. **分镜表**：五列，时间加起来等于总时长。行数按内容加，不硬凑。

| 时间 | 画面 | 口播文案 | 字幕/花字 | 备注 |
|---|---|---|---|---|
| 0-3s | … | … | … | 钩子 |
| 3-8s | … | … | … | 信息点 1 |
| … | … | … | … | … |

4. **口播全文**：用代码块包起来，方便直接进提词器；块里只放要念的字，不放舞台标记。代码块下面紧跟一行标注——`口播正文：<N> 字 → <X> 秒（约 <Y> 字/分）`，再写 BGM 和发布备注（AI 声明、出镜方式、字幕样式）。

**交付前机检**：

```bash
python3 skills/ai-news-content/scripts/check_copy.py out/<日期-事件>/02-抖音口播分镜.md --mode douyin --material material.json
```

## 8. 发布前自检表

**开头**
- [ ] 前 3 秒有钩子，且钩子和内容对得上（纯标题党会被限流）
- [ ] 钩子是一句人话，不是行业黑话

**节奏**
- [ ] 信息点不超过 3 个（30 秒版）
- [ ] 顺序是"反常识 → 悬念 → 数据 → 结论"
- [ ] 每 5–10 秒有一个新刺激（数一遍分镜表的"备注"列）
- [ ] 全篇至少 2 处具体数字，每个数字带主体

**口播**
- [ ] 每句 ≤15 字，已逐句数过
- [ ] 语速 240–280 字/分，末尾标了「口播正文：N 字 → X 秒」
- [ ] 书面语都翻成了人话
- [ ] 没有编造体验（"我用了三个月"这类）

**画面**
- [ ] 分镜表五列齐全，时间加起来等于总时长
- [ ] 每行口播字数 ÷ 4.1 与时间跨度匹配，没有靠慢放凑时长
- [ ] 画面里没有中文，中文都后期贴
- [ ] 补镜素材都有版权交代

**合规**
- [ ] 无绝对化用语
- [ ] CTA 只有一个，且是"涨粉 / 关注系列 / 评论区"三选一
- [ ] AI 生成的画面已勾选 AI 生成声明并加角标
