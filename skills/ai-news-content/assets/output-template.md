# 输出骨架：从素材卡到可发布成品

> **这份文件解决什么问题**：把「素材卡 → 平台成品 → 视觉提示词 → 发布前自检 → 风险与未确认」压成一张固定骨架。写稿、审稿、发布三步对着同一份文件交接，运营拿到 §1 就能直接复制发布。
> 各平台的写法细节在 `references/02-platform-xiaohongshu.md` 和 `references/03-platform-douyin.md`；这里只规定**交付格式**。

---

## 使用说明（先看这 4 条，再往下复制）

1. **文件名**：`out/<YYYY-MM-DD>-<事件短名>/<序号>-<平台>.md`，一个模式一份文件（见文末交付清单）。
2. **尖括号 `<…>`** 是待填位，填完把尖括号一起删掉。
3. **以 `>` 开头的行是填写提示**，交付前整行删掉，别让运营看到。
4. **§1 的成品必须放在代码块里**，块内只放能直接发布的内容，任何备注、来源、解释都写在代码块外。
5. §3、§4 是给自己人看的，**发布时不要复制出去**。


**结果**：FAIL <0> / WARN <n>

```text

```

### 3.2 人工勾选表

**事实与数字**
- [ ] 每个数字都能说出"谁说的、什么时候说的"
- [ ] third-party 的信息都带了主体（"据 XX 报道""据 XX 评测"）
- [ ] 未公布的信息写成"截至 X 月 X 日未公布"，没有写成"不会公布"
- [ ] 没有把第三方转述压成官方口径
- [ ] 自己换算的数字标了"按…折算"

**文案**
- [ ] 标题 3 个备选，每个 ≤20 字，至少一个读者视角
- [ ] 正文 300–800 字，前 3 行已经在讲事
- [ ] 标签 5–8 个（泛 + 垂类 + 自定义都有）
- [ ] 结尾 / CTA 只有一个动作

**视频（做 douyin 时勾）**
- [ ] 每句 ≤15 字，语速与时长对得上
- [ ] 信息点 ≤3 个，每 5–10 秒一个刺激
- [ ] 口播与画面时长匹配，没有靠慢放凑时长

**合规**
- [ ] 无绝对化用语、无站外导流、无编造体验
- [ ] 画面零中文，中文都后期贴
- [ ] AI 生成的画面已勾选 AI 生成声明并加角标

## 4. 风险与未确认

> 填写提示：这一节宁可写多，不要漏。它不参与发布，但出问题时是唯一能自查的底稿。

| 类型 | 具体内容 | 处理方式 |
|---|---|---|
| 单一来源数字 | <哪个数字，只有谁说过> | <加"据 X"或直接删掉> |
| 未公布信息 | <例：许可证截至抓取日未公布> | <写"截至 X 月 X 日未公布"，不写"不会公布"> |
| 预测内容 | <哪句是判断，依据是什么> | <明说"我的判断"+ 给对答案日期> |
| 转述口径 | <哪句是第三方转述> | <带主体，写"据 X 报道"> |
| 别写的话 | <具体哪句> | <为什么：无出处 / 易曲解 / 广告法> |

**发布前最后三问**（三个都答"是"才能发）

1. 每个数字都能说出谁说的吗？
2. 有没有哪句把"没有公布"写成了"不会有"？
3. 预测有没有标成预测、给没给对答案的日期？
